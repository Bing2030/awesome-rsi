Illuminating Search Spaces by Mapping Elites

Jean-Baptiste Mouret, Jeff Clune

arXiv 2015 · 2015

Local PDFOnline

TL;DR

MAP-Elites keeps, in a discretized user-chosen feature grid, the highest-performing solution found for every cell, then mutates those elites to fill and improve the map — returning a diverse repertoire that also beats single-objective search.

Abstract

Many fields use search algorithms, which automatically explore a search space to find high-performing solutions: chemists search through the space of molecules to discover new drugs; engineers search for stronger, cheaper, safer designs, scientists search for models that best explain data, etc. The goal of search algorithms has traditionally been to return the single highest-performing solution in a search space. Here we describe a new, fundamentally different type of algorithm that is more useful because it provides a holistic view of how high-performing solutions are distributed throughout a search space. It creates a map of high-performing solutions at each point in a space defined by dimensions of variation that a user gets to choose. This Multi-dimensional Archive of Phenotypic Elites (MAP-Elites) algorithm illuminates search spaces, allowing researchers to understand how interesting attributes of solutions combine to affect performance, either positively or, equally of interest, negatively. For example, a drug company may wish to understand how performance changes as the size of molecules and their cost-to-produce vary. MAP-Elites produces a large diversity of high-performing, yet qualitatively different solutions, which can be more helpful than a single, high-performing solution. Interestingly, because MAP-Elites explores more of the search space, it also tends to find a better overall solution than state-of-the-art search algorithms. We demonstrate the benefits of this new algorithm in three different problem domains ranging from producing modular neural networks to designing simulated and real soft robots. Because MAP- Elites (1) illuminates the relationship between performance and dimensions of interest in solutions, (2) returns a set of high-performing, yet diverse solutions, and (3) improves finding a single, best solution, it will advance science and engineering.

Method

Inputs are a performance function f(x), N user-chosen feature dimensions, and a discretization of that feature space into cells. Initialization randomly generates G genomes, evaluates each for performance p and feature descriptor b, and keeps the best performer per cell. The loop then repeats I times: uniformly sample a random occupied cell, take its elite genome, produce a variant by mutation and/or crossover, evaluate its descriptor and performance, and write it into its descriptor's cell only if that cell is empty or the offspring outperforms the occupant; otherwise it is discarded. One solution per cell is retained, so the archive is simultaneously population and memory. The experiments use a hierarchical variant that subdivides cells as evaluations accrue, parallelized by farming evaluation batches to cluster nodes.

Key results

  • Neural-network (retina) domain, 20 runs per treatment, 512x512 map, 10,000 evaluations: MAP-Elites scored significantly higher (p < 1x10^-7, two-tailed Mann-Whitney U) than a traditional single-objective EA, Novelty Search + Local Competition, and random sampling on all four metrics (global performance, global reliability, precision, coverage) — including on global performance, the metric the traditional EA optimizes for directly.
  • Simulated soft robots (Voxcad, 10x10x10 voxel space, 128x128 map; 8 MAP-Elites, 5 EA+Diversity and 7 EA runs had finished in time): MAP-Elites had significantly higher global reliability and coverage (p < 0.002), a higher but non-significant median global performance (p > 0.05), and significantly worse precision than the two controls (p < 0.01).
  • The maps expose real tradeoffs: holding voxels filled at ~75%, more stiff bone material monotonically lowers distance travelled (a fast rabbit-like biped becomes a slow turtle with a heavy shell), and a one-voxel-wide 'sheet' island near 7% fill shows anomalously high performance — a region the paper says might take hundreds or thousands of runs of traditional optimization to discover.
  • Lineage analysis in the retina domain: most elites descend from parents within ~0.2 of them in feature space and none of the sampled elites came from a parent more than halfway across the map, yet the full lineages of four sampled elites traverse many regions — evidence that elites elsewhere act as stepping stones.
  • Real soft robot arm (3 Dynamixel AX-18 servos, 64-cell 1-D feature space on the arm tip's x position, performance = max y, 640 evaluations for MAP-Elites and random sampling vs 729 for grid search): all three treatments find approximately the correct boundary for high x (~600 to ~800), but MAP-Elites dominates the harder intermediate range (~400-600) and low x (200-500), where grid search found only a few points. The paper calls these data too preliminary for reliable statistics.

Key advantages

  • Collapses the novelty-search machinery into one archive: no population/archive split and no tuning of the parameters that split requires, O(1) cell lookup instead of O(n log n) nearest-neighbour computations per generation, no cycling, and a selection pressure that is easy to reason about because the only things changing over time are how many cells are filled and their performance.
  • Returns the highest performer per cell rather than a Pareto front or one optimum, so it answers how features trade off against performance — including negative relationships, such as more bone material meaning slower robots, that a performance-driven run would never surface.
  • Illumination is a strict superset of optimization: the same run that fills the map also won the narrow 'single best solution' contest on the deceptive retina problem, which the paper attributes to the diversity of stepping stones rather than to a diversity bonus bolted onto the fitness function.
  • Genuinely simple and cheap to implement (the default version is the short pseudocode loop of Fig. 2), with hierarchical and cluster-parallel versions specified; performance should keep improving with more evaluations because the archive does not collapse onto one local optimum.

Limitations

  • Explicitly a preliminary draft: the author's note states that all experiments will be redone and the data are subject to change, the soft-robot-arm results are 'too preliminary to provide reliable statistical results', and the simulated-robot comparison rests on unequal finished-run counts (8 vs 5 vs 7).
  • Coverage is never guaranteed — some cells may be unreachable because no genome maps to them, and others the search simply fails to reach.
  • Precision (opt-in reliability) was significantly worse than the performance-only controls in the soft robot domain (p < 0.01): a fixed evaluation budget spread across orders of magnitude more cells buys breadth at the cost of depth in any single cell.
  • The feature space must be chosen up front and its cells cannot be added later, so MAP-Elites 'by definition cannot exhibit open-ended evolution' (the paper's own words); it also assumes you cannot take direct steps in feature space, since if you could, exhaustive search there would be simpler.
