Continual Harness: Online Adaptation for Self-Improving Foundation Agents

Seth Karten, Joel Zhang, Tersoo Upaa, Ruirong Feng, Wenzhe Li, Chengshuai Shi, Chi Jin, Kiran Vodrahalli

arXiv 2026 · 2026

Local PDFOnlineCode

TL;DR

Harness engineering for embodied agents, previously human-in-the-loop (Gemini Plays Pokémon finished three RPGs), is automated: a Refiner rewrites the agent's prompt, sub-agents, skills and memory mid-episode with no resets, then an online DAgger+PRM loop updates the model's weights inside that same live-refining harness.

Abstract

Coding harnesses such as Claude Code and OpenHands wrap foundation models with tools, memory, and planning, but no equivalent exists for embodied agents' long-horizon partial-observability decision-making. We first report our Gemini Plays Pokemon (GPP) experiments. With iterative human-in-the-loop harness refinement, GPP became the first AI system to complete Pokemon Blue, Yellow Legacy on hard mode, and Crystal without a lost battle. In the hardest stages, the agent itself began iterating on its strategy through long-context memory, surfacing emergent self-improvement signals alongside human-in-the-loop refinement. Continual Harness removes the human fully from this loop: a reset-free self-improving harness for embodied agents that formalizes and automates what we observed. Starting from only a minimal environment interface, the agent alternates between acting and refining its own prompt, sub-agents, skills, and memory, drawing on any past trajectory data. Prompt-optimization methods require episode resets; Continual Harness adapts online within a single run. On Pokemon Red and Emerald across frontier models, Continual Harness starting from scratch substantially reduces button-press cost relative to the minimalist baseline and recovers a majority of the gap to a hand-engineered expert harness, with capability-dependent gains, despite starting from the same raw interface with no curated knowledge, no hand-crafted tools, and no domain scaffolding. We then close the loop with the model itself: an online process-reward co-learning loop, in which an open-source agent's rollouts through the refining harness are relabeled by a frontier teacher and used to update the model, drives sustained in-game milestone progress on Pokemon Red without resetting the environment between training iterations.

Method

From a minimal interface (frame o_t, ASCII text map, eight buttons) the harness state is four editable stores: prompt p, sub-agents G, skills K, memory M. Inner loop: the agent model reads (s_t, H_t, tau_t) and emits an action. Outer loop: every F steps after a warm-up of W, the Refiner reads tau_{t-F:t}, names failure signatures — navigation loops, tool-call failures, stalled objectives — then runs four passes emitting Delta = (Delta_p, Delta_G, Delta_K, Delta_M) through the same meta-tool API (define_agent, run_code, process_memory): p is replaced, G/K/M get CRUD edits, and H_{t+1} = H_t + Delta enters context with no reset. At training scale each iteration runs pi_theta inside the live-refining harness for K=256 DAgger steps; a pairwise PRM scores transitions (progress 0.4, action 0.3, reasoning 0.2, format 0.1), a Gemini-3.1-pro teacher relabels low-reward windows, and soft SFT (LoRA r=256) produces theta_{k+1} from the carried-over emulator state.

Key results

  • On Emerald's 31-milestone set, Gemini 3 Pro with from-scratch Continual Harness reaches 100% of milestones at a $130 median, against the minimalist harness at 98% for $215 — a ~40% cost reduction with no completion loss; the two bootstrap variants reach 96–100% for $110–$140. On Red, bootstrap-updating is more efficient than from-scratch at every monitored milestone.
  • Gains scale with capability and invert below the floor: Flash bootstrap-updating reaches 80% of Emerald milestones at $42 vs Hmin's 77% at $30 (high variance across seeds), while Flash-Lite's Hmin gets 20% at $11 and every Continual Harness variant falls to 3–13% at comparable or higher cost.
  • Skills measurably self-improve toward an oracle: for the top-10% evolved navigation skills on a 24-hour Pro run, path-cost deficit against a Dijkstra oracle falls from a near-half-cost penalty to single digits, with the repair happening in the same episode as the failure. Hmin never invokes a navigation skill; every Continual Harness condition logs hundreds of invocations.
  • Co-learning drives sustained reset-free progress: five advancing Gemma-4 runs on Pokémon Red raise their milestone index across training iterations (net objective gains +2 to +5, judge-verified), from both the beginning of the game and mid-game checkpoints, against zero advance for the untrained baseline. Cross-family Qwen3.5 35B parses tool calls through the harness but cannot leave the starting area.
  • The human-in-the-loop predecessor is the existence proof: GPP is the first AI system to complete Pokémon Blue (May 2025), Yellow Legacy on hard mode (August 2025) and Crystal without a lost end-game battle (November 2025). On Crystal, Gemini 3 Pro matched Gemini 2.5 Pro's early milestones in roughly half the turns and ~60% fewer tokens, against 16,403 turns spent by 2.5 Pro before the Fog Badge.

Key advantages

  • Reset-free is a structural difference, not a convenience: failure signatures observed earlier stay available to every later refinement pass, so refinement quality compounds with episode length, and the loop can target failure modes that only appear deep in an episode (late-game battles, multi-step puzzles, dialogue chains) which reset-based prompt optimizers such as GEPA cannot reach by construction.
  • The evolved object is the entire harness state, not just the prompt — p, G, K and M are all rewritten by the same Refiner through the same meta-tool API the agent itself uses, with per-component mechanism attribution (Appendix C) instead of one aggregate ablation.
  • Skill quality is measured against an external oracle (BFS/Dijkstra path cost on navigation segments) rather than end-task efficiency, giving a task-independent mechanism-level read on self-improvement that most harness papers do not attempt.
  • It is the arm of the harness-school arc that closes the loop into weights: DAgger rollouts through the live-refining harness, pairwise PRM scoring, frontier-teacher relabeling and soft SFT produce model-harness co-learning, with capability-dependent evidence for whom it helps.

Limitations

  • A hard capability floor: on Flash-Lite every Continual Harness variant reaches only 3–13% of Emerald milestones at comparable or higher cost than Hmin's 20% at $11, and Flash is high-variance. In the authors' own words the framework needs a model that will sufficiently utilize the harness components.
  • The residual gap to the hand-engineered expert harness concentrates in dialogue-heavy gym interiors and multi-turn battle strategy — components the loop does not yet synthesize reliably.
  • Co-learning couples a frontier teacher (Gemini-3.1-pro) to an open-source student; Gemma-4 up to 31B is not capable enough to serve both roles, the loop has no established convergence point, and no head-to-head comparison against reset-based batch accumulation was run.
  • Memory reuse is weak by the authors' own admission — most authored entries sit unused and the reference rate stays low in absolute terms. On Red the bootstrap-updating agent collapses its sub-agent budget to a handful of calls citing IDs absent from the bootstrap (inherited share 6.4% ± 5.7 vs 100.0% ± 0.0 frozen, Table 2), and the milestone staircase regresses below Hmin in lockstep; a reuse prior or sub-agent deletion policy is named as the fix.
