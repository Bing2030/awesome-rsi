SkillRise: Agentic Reinforcement Learning for Cross-Task Skill Evolution

Zhiyuan Yao, Yuxin Chen, Zhengxi Lu, Zishan Xu, Yueqing Sun, Yifu Guo, Yuquan Lu, Zhengzhou Cai, Kangning Zhang, Zhuowen Han, Zi-Han Wang, Ziang Ye, Qi Gu, Xunliang Cai, Weiwen Liu, Yongliang Shen

arXiv 2026 · 2026

Local PDFOnline

TL;DR

SkillRise trains one policy to alternate between solving a task and rewriting a textual skill document it hands to the next task, supervised by decoupled credit assignment over ordered sequences of related tasks (+2.3–8.5 pp over GiGPO).

Abstract

Large language model agents often encounter related yet distinct tasks that share reusable solution patterns. Yet standard agentic reinforcement learning treats tasks as independent episodes, while existing approaches to skill learning either focus on repeated attempts of one task or use pipelines with multiple stages that entangle extraction, retrieval, and execution. We introduce SkillRise, a unified reinforcement learning framework for learning skills across tasks. SkillRise organizes related instances into progressively challenging sequences and uses a single policy to alternate between task solving and curating an evolving skill document passed directly to the next task. Decoupled credit assignment across tasks supervises solving with the current task outcome and curation with discounted downstream outcomes. Experiments on ALFWorld, WebShop, and ScienceWorld show that SkillRise achieves the strongest Pass@1 performance among the compared methods, with gains over the strongest baseline ranging from 2.3 to 8.5 percentage points. Although trained across distinct tasks, its learned curation policy remains effective for repeated attempts on the same task. Further analysis reveals scaling at test time across tasks: performance improves with longer sequences of related tasks even when each task is attempted only once. This trend suggests that SkillRise reuses transferable skills across tasks rather than benefiting from repeated sampling of the same task. SkillRise further retains strong performance while substantially reducing the runtime overhead of skill learning pipelines with multiple stages. Together, these results provide a simple and efficient training paradigm for LLM agents to extract, refine, and reuse transferable skills across tasks.

Method

Sequences are built by partitioning instances on environment-provided family metadata, greedily grouping diverse instances, then ordering them simple→complex by task attributes (WebShop: product category, ascending required attributes/options); training uses K=3. One shared policy π_θ plays two roles under role-specific prompts: it solves task x_i conditioned on the textual skill document S_{i-1}, then rewrites that whole document from (S_{i-1}, τ_i, r_i), with S_0=∅ and only S_i crossing to the next task — earlier trajectories never enter a later solving context. N=8 independent trials per sequence each evolve their own document. Credit is decoupled: solving is scored by the current reward r_i, curation by the discounted Σ_{j>i} γ^{j-i} r_j (γ=0.6), and group-relative advantages are computed per sequence position and phase so the two roles never baseline each other; a clipped PPO-style objective then updates both jointly. Curation prompts mandate abstraction, grounding in the observed attempt, pitfalls, and concision.

Key results

  • Qwen3-4B Pass@1: 85.9% ALFWorld, 84.4% WebShop, 54.6% ScienceWorld — beating the strongest baseline GiGPO (83.6 / 77.3 / 46.1) by +2.3, +7.1, +8.5 points.
  • Within-task generalization despite cross-task training (Pass@3, retrying the same held-out task with the carried document): 92.2 / 96.1 / 61.0, ahead of the strongest baseline by 0.8 / 1.6 / 5.5 points and of LaMer — trained explicitly on repeated same-task attempts — by 0.8 / 1.6 / 14.2 points.
  • Cross-task test-time scaling (ALFWorld, same 128 held-out tasks repartitioned into sequences of length K, each attempted only once): 83.6% at K=2 → 87.5% at K=6, while GRPO, GiGPO and LaMer show no sustained growth; the margin over the strongest baseline widens from 3.9 to 8.6 points.
  • Backbone scaling on ALFWorld: Qwen3-1.7B 78.1% vs GRPO 75.0 (+3.1 points); Qwen3-4B 85.9% vs 79.7 (+6.2), with SkillRise gaining +7.8 points from 1.7B→4B against +4.7 (GRPO) and +3.3 (LaMer).
  • Pipeline efficiency: 85.9% ALFWorld average matches RetroAgent (85.9%) and beats SkillRL by 12.5 points while RetroAgent and SkillRL need 6.0× and 4.3× SkillRise's end-to-end runtime under the same 8×H800 configuration.

Key advantages

  • Makes the skill artifact itself the supervised object: the document is the sole channel between tasks, so later-task outcomes score curation directly — removing the extraction/retrieval/execution entanglement that makes multi-stage pipelines (RetroAgent's memory buffer plus utility updates, SkillRL's teacher distillation + SkillBank + cold-start SFT + retrieval) hard to attribute.
  • Shows the learned curation policy transfers outside its training regime: it wins repeated same-task attempts (Pass@2/3) even though trained only across distinct tasks, and yields monotone cross-task test-time scaling where each task gets one attempt — so the gain is reusable procedure, not extra sampling of one instance.
  • Genuinely compact end-to-end: one policy, no external teacher, no separate memory store or retrieval module (SkillRL's reproduction needs Gemini-2.5-Pro as teacher), and the result is robust to the cross-task discount — γ∈{0.3,0.4,0.6,0.7} converge within roughly one point.
  • The curation ablation isolates the mechanism: a no-curation variant with the same K=3 related-task sequences and the same interaction budget trails SkillRise by about 3 points and GRPO by more than 6, so sequencing related tasks alone is not enough — the explicit rewrite step carries the improvement.

Limitations

  • Assumes task-family metadata: sequences come from environment-provided family labels plus hand-chosen difficulty attributes (product category, attribute/option counts); automatically discovering relatedness in open-ended task streams is left open (§8).
  • Narrow evidence base: three text benchmarks (ALFWorld, WebShop, ScienceWorld) with verifiable outcome rewards, 128 held-out instances each, and backbones capped at Qwen3-4B for compute reasons.
  • Training sequences are K=3 while test-time scaling is probed up to K=6, so the longest-horizon behavior is extrapolation; and the no-curation ablation's ~3-point gap suggests the headline gains rest mostly on related-task sequencing plus a modest curation increment.
  • The document is sequence-local and thrown away per sequence (every trial restarts from S_0=∅), so there is no accumulating lifelong skill library; curation quality is also bounded by the policy's own reflection ability, with the rewrite rules (abstract, ground, extract pitfalls, stay concise) hand-authored per environment.
