From Procedural Skills to Strategy Genes: Towards Experience-Driven Test-Time Evolution

Junjie Wang, Yiming Ren, Haoyang Zhang

arXiv 2026 · 2026

Local PDFOnline

TL;DR

Across 4,590 trials on 45 scientific code tasks, a compact ~230-token "strategy gene" beats documentation-heavy skill packages for test-time control (54.0% vs 49.9% avg) and carries evolved failure experience better.

Abstract

This beta technical report asks how reusable experience should be represented so that it can function as effective test-time control and as a substrate for iterative evolution. We study this question in 4.590 controlled trials across 45 scientific code-solving scenarios. We find that documentation-oriented Skill packages provide unstable control: their useful signal is sparse, and expanding a compact experience object into a fuller documentation package often fails to help and can degrade the overall average. We further show that representation itself is a first-order factor. A compact Gene representation yields the strongest overall average, remains competitive under substantial structural perturbations, and outperforms matched-budget Skill fragments, while reattaching documentation-oriented material usually weakens rather than improves it. Beyond one-shot control, we show that Gene is also a better carrier for iterative experience accumulation: attached failure history is more effective in Gene than in Skill or freeform text, editable structure matters beyond content alone, and failure information is most useful when distilled into compact warnings rather than naively appended. On CritPt, gene-evolved systems improve over their paired base models from 9.1% to 18.57% and from 17.7% to 27.14%. These results suggest that the core problem in experience reuse is not how to supply more experience, but how to encode experience as a compact, control-oriented, evolution-ready object.

Method

A gene is a frozen-model control object injected through systemInstruction: ~230 tokens of signals_match (domain keywords), a one-sentence summary, an ordered strategy list with AVOID cues, and optional constraints/validation hooks, distilled from a skill document, prior trajectories, or a validated capsule. The Gene Evolution Protocol canonicalizes it and updates it through a six-stage loop — SCAN runtime traces and execution failures, SIGNAL (convert raw traces into standardized triggers), INTENT (repair, optimize, or extend), MUTATE (rewrite strategy steps, AVOID cues, or metadata), VALIDATE (sandbox execution against the validation hooks), SOLIDIFY (write the passing asset back into the gene/capsule store and log an immutable event). Genes are the atomic control unit; capsules record validated execution paths; events are the audit log. Base-model weights never change.

Key results

  • Headline (Table 1, 4,590 trials): Gene 54.0% average pass rate, +3.0pp over no guidance (51.0%); the full ~2,500-token Skill package scores 49.9% (−1.1pp). Skill lifts Flash 41.8→49.0% but drags Pro 60.1→50.7%; Gene holds Pro at 59.9% and lifts Flash to 48.2%.
  • Skill's usable signal is sparse (Table 12): Skill-Workflow 52.5% (+1.5pp) is the only clearly helpful section, while Skill-Overview 46.3% (−4.7pp) is the most harmful. Trimmed to Gene's ~230-token budget (Table 13), Skill-Pitfalls-Short reaches 52.0% (+1.0) and Skill-Workflow-Short 51.5% (+0.5) — closer, but still below Gene's 54.0%.
  • The gain is not brevity (Table 2): keywords-only 53.5% (+2.5pp) already beats keywords+summary at 51.0% (+0.0), and only the full keywords+summary+strategy gene reaches 54.0%. Reattaching documentation dilutes it (Table 3): Gene+API notes 51.5%, Gene+examples 52.0%, both below Gene alone. Naive composition fails (Table 4): two complementary genes 44.9% (−6.1pp), three 50.4%, two conflicting 53.2%, single gene 54.0%.
  • Structurally robust but content-sensitive (Table 14): inverted priority 52.8%, overconstrained 55.9% and stale paradigm 56.6% stay at or above clean Gene (54.0%), whereas wrong algorithm 48.8% and wrong domain 49.4% collapse it.
  • Evolution carrier (Tables 5–7): Gene+failure 52.0% beats Skill+failure 47.8% and freeform+failure 49.6%; flattening Gene into prose drops it to 50.5% (−0.5pp); failure-warnings-only reaches 54.4% (+4.6pp), the best condition in that probe, above strategy-only 52.3% and both mixed orderings. On CritPt, Evolver (Gene) 2026-02-16 scores 18.57% vs 9.1% for Gemini 3 Pro Preview (+9.47), and the 2026-03-26 run 27.14% vs 17.7% for Gemini 3.1 Pro Preview (+9.44), at ~$0.81 in observed input/output tokens — the authors' own estimate, ~32.1× below the reported $26 benchmark cost.

Key advantages

  • The largest controlled probe of experience representation in this catalog: 4,590 retained trials over 45 scenarios, two fixed models, one shared pipeline (T=0.05, 16,384 max output tokens, control injected through systemInstruction separately from the task in contents, 120s sandbox timeout), so deltas isolate the representation rather than the task set or decoding.
  • It separates packaging from content twice. Budget-matched ~230-token Skill fragments still lose to Gene, and the same gene flattened into prose loses most of its +3.0pp — so the win is control-oriented schema, not token count. Reattaching the documentation Gene deliberately dropped always loses.
  • It shows experience accumulation must be selective rather than additive: failure-warnings-only (54.4%, +4.6pp) beats both mixed strategy/failure bundles, and naive composition of nominally complementary genes is the worst condition measured (44.9%, −6.1pp) — a concrete negative result against the bag-of-skills assumption.
  • GEP is a real protocol rather than a prompt format: typed gene/capsule/event objects, an explicit six-stage loop, an open reference implementation (EvoMap/skill2gep), and a demonstrated end-to-end payoff on CritPt where the base weights never change.

Limitations

  • Scope is 45 scientific code-solving scenarios scored by Python checkpoints under two Gemini 3.1 models; no non-code domain, no second model family, and no seed variance or confidence intervals, so the ~1pp scale of several deltas is not bracketed.
  • It is a self-described "beta technical report" with no limitations section; capsules and events are "paper-side formalizations" that are never empirically evaluated — only the gene layer is tested.
  • Reuse has an unresolved scope boundary: naive composition of complementary genes collapses to 44.9% and reattaching documentation always loses, so the paper can demonstrate when Gene fails but not yet how to select or combine genes in practice.
  • The CritPt evidence is two ~2-day single runs of two successive versions against their own paired base models (+9.47, +9.44), with no seed variance and no ablation of which genes carried the gain across 70 tasks, 210 gene slots and 36 gene IDs; the $0.81 cost figure excludes reasoning tokens by the authors' own caveat, and several perturbations actually beat the clean gene (overconstrained 55.9%, stale paradigm 56.6% vs 54.0%), which the authors explain only post hoc — the mechanism is not fully characterized.
