Language Agent Tree Search Unifies Reasoning, Acting, and Planning in Language Models

Andy Zhou, Kai Yan, Michal Shlapentokh-Rothman, Haohan Wang, Yu-Xiong Wang

ICML 2024 · 2024

Local PDFOnline

TL;DR

LATS puts a frozen LM inside Monte Carlo Tree Search: the ReAct agent proposes actions, an LM value function plus self-consistency scores states, the environment supplies rewards, and reflections on failed trajectories are re-injected as context.

Abstract

While language models (LMs) have shown potential across a range of decision-making tasks, their reliance on simple acting processes limits their broad deployment as autonomous agents. In this paper, we introduce Language Agent Tree Search (LATS) -- the first general framework that synergizes the capabilities of LMs in reasoning, acting, and planning. By leveraging the in-context learning ability of LMs, we integrate Monte Carlo Tree Search into LATS to enable LMs as agents, along with LM-powered value functions and self-reflections for proficient exploration and enhanced decision-making. A key feature of our approach is the incorporation of an environment for external feedback, which offers a more deliberate and adaptive problem-solving mechanism that surpasses the constraints of existing techniques. Our experimental evaluation across diverse domains, including programming, interactive question-answering (QA), web navigation, and math, validates the effectiveness and generality of LATS in decision-making while maintaining competitive or improved reasoning performance. Notably, LATS achieves state-of-the-art pass@1 accuracy (92.7%) for programming on HumanEval with GPT-4 and demonstrates gradient-free performance (average score of 75.9) comparable to gradient-based fine-tuning for web navigation on WebShop with GPT-3.5. Code can be found at https://github.com/lapisrocks/LanguageAgentTreeSearch

Method

Node s=[x, a1..i, o1..i] holds the input plus action/observation history, so any state is restored by replaying text — no world model. Each of k iterations runs six operations. Selection descends by UCT, V(s)+w·sqrt(ln N(p)/N(s)), w=1. Expansion samples n=5 actions from the ReAct agent pθ; the environment returns observations and n children enter an external memory tree. Evaluation assigns V(s)=λ·LM(s)+(1−λ)·SC(s): an LM prompted after seeing environment feedback to emit a scalar score, plus a self-consistency score (λ=0.5 on HotPotQA/Game of 24, 0.8 on programming/WebShop). Simulation rolls to a terminal state for reward r (answer correctness, fraction of tests passed, purchase success). Backpropagation sets V(s)←(V_old(s)(N−1)+r)/N along the path. On failure a reflection prompt rewrites the context used by both agent and value function.

Key results

  • HumanEval pass@1 with GPT-4 (Table 4): LATS 92.7 vs 80.1 zero-shot and 91.0 for Reflexion, reported as state of the art; with GPT-3.5, 83.8 vs Reflexion 68.1, RAP 63.1, ReAct 56.9, ToT 54.4, CoT 46.9 (n=5, k=8).
  • MBPP with GPT-3.5 (Table 5), 397-problem subset: 81.1 pass@1 vs RAP 71.4, Reflexion 70.0, ReAct 67.0, ToT 65.8, CoT 54.9.
  • HotPotQA, 100 questions, exact match (Tables 2–3): reasoning LATS(CoT) 0.62 vs RAP 0.60, ToT 0.55, CoT-SC 0.38, base 0.32; acting LATS(ReAct) 0.63 vs RAP(ReAct) 0.54, Reflexion 0.51, ReAct 0.32; chaining CoT then ReAct reaches 0.71. Game of 24 (Table 7): 0.44 vs RAP 0.40, ToT 0.20, Reflexion 0.12, CoT 0.08.
  • WebShop, 50 instructions (Table 6): frozen GPT-3.5 scores 75.9 / 38.0 success rate vs Reflexion 64.2/35.0 and ReAct 53.8/28.0, above imitation learning 59.9/29.1 and IL+RL 62.4/28.7; fine-tuning leads on SR (45.0) at 67.5 score.
  • Ablations on HotPotQA (Table 8): removing the LM value function costs 0.26 EM (0.63→0.37), replacing MCTS with DFS 0.21 (0.63→0.42), removing reflection 0.05 (0.63→0.58); λ=1 also drops Game of 24 (Table 13) from 0.44 to 0.40. Cost (Tables 9–10): same O(kn) sample complexity but fewer nodes to success — 28.42 vs RAP 31.53 and ToT 33.97 at k=10, averaging 3.55 and 12.12 fewer.

Key advantages

  • First framework to combine reasoning, acting, planning, self-reflection and external memory in one loop (Table 1): it searches a ReAct thought-plus-action space with environment feedback, where ToT searches thoughts only, RAP needs an LM world model, and Reflexion refines a single trajectory.
  • The value function is the load-bearing part: LM scoring happens after environment feedback (ToT scores before it), and the added self-consistency term sharpens it — ablating LM scoring costs 0.26 EM, more than any other component, and λ=1 falls to 0.40 on Game of 24.
  • Trained-policy performance with no training: frozen GPT-3.5 plus search beats imitation learning and IL+RL on WebShop (75.9 vs 59.9/62.4) and approaches the fine-tuned model, while with GPT-4 it sets the then-state-of-the-art HumanEval pass@1 of 92.7 — no RL, no gradient updates.
  • Search is guided rather than merely wider: same asymptotic sample complexity as ToT and RAP but fewer nodes and fewer tokens to reach success, and the n parameter gives an explicit accuracy-cost dial (n=1 makes it as cheap as ReAct with multiple trials).

Limitations

  • The authors' own two: higher computational cost than simple prompting methods like ReAct or Reflexion, and the need for environments that permit reverting to earlier states (they argue this holds for HumanEval, WebShop, Alfworld, ToolBench, but not universally).
  • They also call their own benchmarks relatively simple versus real-world interactive environments; there is no long-horizon or embodied test, and multi-agent and more complex environments are left to future work.
  • The reward is privileged. HotPotQA uses an oracle telling the agent whether its answer is correct, and programming grades against LM-generated assert statements — the oracle-label setup Huang et al. (2310.01798) single out when criticising self-correction claims.
  • Reflection contributes little where search already covers it: only 0.05 EM on HotPotQA versus Reflexion's 0.19 gain over ReAct, and the WebShop analysis finds generated reflections often generic, leaving the agent prone to local minima.
