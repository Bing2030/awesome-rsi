EvoHarness-RL: Learning Self-Evolving Runtime Harness for Long-Horizon LLM Agents

Xuying Ning, Dongqi Fu, Tianxin Wei, Hanqing Zeng, Yuanchen Bei, Bingxuan Li, Zihao Li, Qifan Wang, Xiang Shen, Yifan Wu, Jiayi Liu, Hong Li, Yinglong Xia, Xiangjun Fan, Hanghang Tong, Jingrui He

COLM 2026 (LLA Workshop) · 2026

Local PDFOnline

TL;DR

EvoHarness-RL makes harness use a learned policy: a BPE workspace (Belief/Progress/Experience) with four meta-actions (track/commit/recall/note) is taught by SFT then cost-aware GRPO, lifting Qwen3-8B on ALFWorld from 47.9% to 96.9% seen, 86.6% unseen.

Abstract

Long-horizon LLM agents increasingly rely on external execution support to maintain state, track progress, invoke tools, verify outcomes, and reuse experience across interactions. However, effective harness use raises two coupled challenges: state formation from noisy interaction traces and runtime control over external-state access. Existing agents usually handle both through prompts, heuristics, or domain-specific conventions, leaving the external workspace and its usage policy manually engineered. To address this, we study the problem of harness policy learning, where agents learn harness policies offline and deploy them to construct and update external harness state online during runtime task execution. We introduce EvoHarness-RL, which exposes Belief, Progress, and Experience (BPE) as policy-facing harness state. Supervised harness fine-tuning teaches the base agent the harness action space and how to construct useful external state, while cost-aware GRPO explores coordination policies to selectively read, update, and consolidate that state during long-horizon interaction. Instantiated on ALFWorld with a Qwen3-8B LLM, EvoHarness-RL reaches 96.9% success and reveals two key dynamics: harness annealing, where training internalizes recurring harness-use patterns into the model policy and shifts the agent from frequent harness calls toward selective external-state access, and harness evolution, where progress updates and experience consolidation refine the harness into a compact, task-adaptive state substrate. These results suggest that long-horizon agents benefit from trainable policies for constructing and coordinating with external harness workspaces, beyond simply adding stronger tools or larger memories.

Method

EvoHarness-RL externalizes the workspace into BPE state Ht=(Bt,Pt,Et): Belief (ALFWorld: a rule-based world-state tracker updated after each environment step), Progress (a bounded committed-subgoal list), Experience (a four-category skill bank — general, task-specific, common mistakes, object→location search priors — with keyword-overlap recall, LFU eviction, 80 entries/category). The policy interleaves four meta-actions with environment actions under one shared step budget: track [object|world], commit [subgoal], recall [query], note [insight]. Stage 1, supervised harness fine-tuning: SFT Qwen3-8B on 87 successful Claude-Opus teacher trajectories (1,153 next-action pairs from 500 games; teacher makes 405 harness calls, ~18% of turns), whose accumulated store seeds the skill bank. Stage 2, cost-aware GRPO from that checkpoint: R = 10·1[solved] + success-gated efficiency term max(0,1−|τ|/70) + cosine-annealed action-diversity bonus − spam/invalid-format penalties, KL β=0.01 to the SFT reference. At epoch boundaries an external consolidation model merges buffered notes into the bank via add/update/remove.

Key results

  • ALFWorld seen split, Qwen3-8B (140-task validation): ReAct 47.9% → prompt-time BPE 56.4% → SFT 68.6% → GRPO 96.9% (+49.0 over ReAct); beats trainable baselines GRPO 65.6%, SkillOS 80.2%, SkillRL 89.9%, and matches Claude Opus 4.5 ReAct (96.4%; 98.5% with the prompt-time BPE harness)
  • Unseen split: 50.0% (ReAct) → 77.6% (prompt-time BPE) → 69.4% (SFT, a drop) → 86.6% (RL) — cost-aware GRPO recalibrates harness access that imitation over-fits to seen tasks
  • Prompt-time BPE alone lifts frontier models: GPT-4.1 47.9 → 70.0 (+22.1), GPT-5 60.7 → 85.0 (+25.7), Claude Opus 4.5 96.4 → 98.5
  • Component ablation (frozen Qwen3-8B, prompt-time BPE): removing any of Belief/Progress/Experience drops 56.4% into the 48.6–50.7% range, with Experience removal the lowest (48.6%, §3.3)
  • Two dynamics: harness annealing — mean harness calls fall from the SFT scaffold's frequent use to ≈1 per episode, recall persisting while commit/note decay to ~0 (Figs. 3, 5); harness evolution — add/update/remove consolidation plus LFU eviction keep the skill bank compact while training reward stays above standard GRPO throughout (Fig. 6)

Key advantages

  • Makes harness access a first-class learnable decision: harness actions spend the same step budget as environment actions, so the policy learns when external state is worth its cost — the mechanism behind both the SFT→RL seen jump (68.6→96.9) and the unseen recovery (69.4→86.6, where SFT alone underperforms the 77.6 prompt-time harness)
  • Unifies within-episode state tracking (Belief, Progress) and cross-episode skill curation (Experience) under one policy-facing interface and one four-action protocol; the paper's position is that prior self-evolving agents keep these two separated
  • Names and evidences two co-evolutionary dynamics — harness annealing (the policy internalizes routine scaffold calls, with action-specific decay rates in Fig. 5) and harness evolution (consolidation plus LFU eviction yield a compact, revisable skill bank rather than append-only memory) — while Fig. 6 rules out policy collapse as the explanation for fewer calls
  • Cheap, inspectable grounding: the ALFWorld harness is deterministic where possible (rule-based belief parser, keyword-overlap recall, LFU eviction); no LLM calls sit inside the rollout loop, and consolidation runs outside it at epoch boundaries

Limitations

  • Single-environment evidence: everything is ALFWorld, and Appendix A concedes the learned action mix is environment-dependent — it 'should not be interpreted as learning a fixed universal harness-action distribution'; Belief/Progress/Experience emphasis would shift in SWE or visually grounded settings
  • SFT alone generalizes worse than the prompt-time harness (69.4% vs 77.6% unseen): supervised imitation copies teacher harness-use patterns without learning when access is worthwhile; only GRPO fixes it
  • Dense reward shaping is load-bearing: with success as a sparse 10·1[solved] gate, the time-annealed diversity bonus, spam/format penalties, and cosine curriculum are all needed to keep the policy from ignoring harness actions or falling into repetition loops
  • Frontier-model dependence in the loop's periphery: Claude Opus supplies all 87 SFT trajectories (kept from 500 games) and every consolidation add/update/remove decision; the belief tracker is also only a rule-based parser, adequate for ALFWorld's text state

Where it fits the RSI arc

Stage 5 (Harness-level RSI), the RL flavor: rather than searching or rewriting scaffold code (AutoHarness, SoL-Pi, Continual Harness) or distilling a harness into weights (Harness-Zero), it keeps the harness implementation fixed and trains the policy to construct and access its state while the experience store co-evolves. Pairs with ACE (evolving context) and the SkillOS/SkillRL baselines it beats.
