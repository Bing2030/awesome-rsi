RSIAgent: Autonomous Exploration for Recursive Self-improvement in New Environments

Sibo Zhu, Shicheng Fan, Xinyue Wang, Wenyi Wu, Kun Zhou, Biwei Huang

arXiv 2026 · 2026

Local PDFOnlineCode

TL;DR

Training-free recursive self-improvement for brand-new computer environments: curriculum, actor, and verifier agents explore with a broad-then-deep strategy and consolidate verified experience into a memory that is frozen for test-time reuse — lifting open models (GLM-5.3 + Kimi-K3) past GPT-6 Astra on OSWorld 2.0 and Agents' Last Exam.

Abstract

Digital agents must often adapt to new environments whose interfaces, tools, and failure modes are not fully captured by pretrained models. We introduce \textbf{RSIAgent}, a training-free multi-agent framework for recursive self-improvement through autonomous memory construction. RSIAgent coordinates curriculum, actor, and verifier agents to continually explore the environment, validate outcomes, and retain environment-specific knowledge, including reusable causal relationships between actions, conditions, and consequences. It further adopts a \textbf{broad-then-deep} exploration strategy, combining parallel broad recursive self-exploration for discovering diverse environment structures with focused deep self-exploration for uncovering hard cases, hidden constraints, boundary conditions, and previously unknown causal dependencies. The resulting memory is frozen and can be directly reused for downstream tasks without updating model parameters. Experiments on OSWorld-v2 and Agent's Last Exam show that RSIAgent substantially improves strong open-source models, enabling Kimi-K3 and GLM-5.3 to outperform frontier closed-source models including GPT-6.

Method

One durable, evolvable memory driven by three coordinated roles: a curriculum agent generates practice tasks from knowledge gaps and decides when practice stops; actor agents execute them code-as-policy and distill their own verified experience back into memory; a verifier agent judges outcomes from environment evidence alone, isolated from the actor's private reasoning to reduce correlated errors. Exploration is broad-then-deep — Broad Recursive Self-exploration (BRS) runs parallel task waves from a shared memory snapshot, consolidated serially per wave with budgets checked at wave boundaries; Deep Recursive Self-exploration (DRS) then does sequential, progressively harder targeted practice, each verified experience committed before the next task is proposed. At test time the memory is frozen and the curriculum agent and memory updates are disabled.

Key results

  • OSWorld 2.0 (0808 offline, 82 tasks): partial score 71.97 -> 78.98 and binary accuracy 37.80 -> 42.68 with the same harness and frozen models — above GPT-6 Astra (72.60) and Claude Opus 5 (70.19).
  • Agents' Last Exam Near-term (67 tasks): 83.75 -> 84.82 partial, 49.25 -> 50.75 binary — above GPT-6 Astra (82.26).
  • Stage ablation on four OSWorld tasks: full broad+deep 74.54 mean vs 65.52 broad-only and 56.50 deep-only; deep-only from empty memory falls below the baseline on two tasks, so starting focused can hurt.
  • GameCraft-Bench (40 tasks): improves game quality from both weak and strong base generators, where the Play2Code baseline degrades already-strong games; RSI experience adds further gain on every generator.

Limitations

  • The headline RSI column is not a matched re-run: only 41/82 OSWorld tasks (19/67 ALE) have recorded RSI entries, baseline scores are retained for the rest, and selected retries/checkpoints with differing budgets are included — the repo's PAPER.md documents this aggregation scope.
  • The acceptance signal is an LLM verifier reading environment evidence, not executed tests; the paper's own failure analysis finds verifier PASS without full requirement coverage and incorrect rules persisting in memory — the failure class rsif moves behind programmatic held-out gates.
  • Per-environment exploration is expensive (Linux host, Docker/KVM VMs, nominal eight BRS projects per target); gains are demonstrated on two computer-use benchmarks plus one game-development setting.

Where it fits the RSI arc

The closest large-scale cousin of rsif's design: weights frozen, a single artifact (memory) evolves under a trusted outer protocol, verification is separated from acting and isolated from the actor's reasoning, and the result is frozen before evaluation. rsif generalizes the evolving surface (prompt/skill/module/memory/policy/meta), replaces the LLM verifier with executed held-out gates plus canaries, and adds archive/promotion/rollback; RSIAgent shows the pattern surviving at full computer-use scale with open models. Its curriculum actor also mirrors rsif's improver-as-proposal-generator split.

How to read it

Read Sections 3.2-3.3 for the role split and broad/deep staging, then Section 4.6's failure-mode taxonomy (untargeted exploration, incomplete verification, unreliable memory consolidation) as a checklist for any RSI loop; the repo's docs/ARCHITECTURE.md maps paper stages onto runnable phases (BRS/DRS/test-time reuse).
