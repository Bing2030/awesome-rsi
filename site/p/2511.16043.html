PAPER · stage 6 · Multi-Agent Self-Improvement

Agent0: Unleashing Self-Evolving Agents from Zero Data via Tool-Integrated Reasoning

Peng Xia, Kaide Zeng, Jiaqi Liu, Can Qin, Fang Wu, Yiyang Zhou, Caiming Xiong, Huaxiu Yao

arXiv 2025 · 2025

Local PDFOnline

TL;DR

Agent0 evolves math-reasoning agents from zero human data by co-evolving two RL-trained agents — a curriculum generator rewarded for frontier-difficulty, tool-heavy tasks and a tool-using executor trained on majority-vote pseudo-labels — lifting Qwen3-8B-Base 18% on math and 24% on general reasoning.

Abstract

Large Language Model (LLM) Agents, often trained with Reinforcement Learning (RL), are constrained by a dependency on human-curated data, limiting scalability and tethering AI to human knowledge. Existing self-evolution frameworks offer an alternative but are typically restricted by the model's inherent capabilities and single-round interactions, hindering the development of complex curricula involving tool use or dynamic reasoning. We introduce Agent0, a fully autonomous framework that evolves high-performing agents without external data through multi-step co-evolution and seamless tool integration. Agent0 establishes a symbiotic competition between two agents initialized from the same base LLM: a curriculum agent that proposes increasingly challenging frontier tasks, and an executor agent that learns to solve them. We integrate external tools to enhance the executor's problem-solving capacity; this improvement, in turn, pressures the curriculum agent to construct more complex, tool-aware tasks. Through this iterative process, Agent0 establishes a self-reinforcing cycle that continuously produces high-quality curricula. Empirically, Agent0 substantially boosts reasoning capabilities, improving the Qwen3-8B-Base model by 18% on mathematical reasoning and 24% on general reasoning benchmarks. Code is available at https://github.com/aiming-lab/Agent0.

Method

From one base LLM (Qwen3-4B/8B-Base), Agent0 clones two agents and alternates GRPO training over 3 iterations. Curriculum agent: generates tasks under reward RC = Rformat·max(0, λunc·Runc + λtool·Rtool − Rrep), where Runc = 1−2|p̂−0.5| peaks when the executor's self-consistency over k=10 sampled solutions is 50% (frontier difficulty), Rtool = γ·min(Ntool, 4) counts code-execution calls in executor responses, and Rrep penalizes BLEU-clustered duplicate tasks. Executor: the frozen curriculum agent emits a task pool; tasks in the intermediate self-consistency band (|p̂−0.5| ≤ δ, δ=0.25) are kept, the majority vote becomes the pseudo-label, and training uses ADPO — advantages scaled down on low-consistency (noisy-label) tasks while the upper clip is relaxed there so low-probability tokens (new reasoning paths) can grow. Rollouts are multi-turn tool-integrated reasoning: generation pauses at python code blocks, a sandbox returns the output, looping until a boxed answer.

Key results

  • Qwen3-8B-Base, math AVG (AMC/MATH/GSM8K/Olympiad/Minerva/AIME24-25): 49.2 → 58.2 (+18%); AIME24 13.9 → 28.0, AIME25 16.7 → 24.8, Minerva 50.0 → 61.3. General benchmarks: MMLU-Pro 51.8 → 63.4, SuperGPQA 28.3 → 33.0, BBEH 8.6 → 13.7 (abstract's +24% is the relative gain across the three general benchmarks; Table 2 'Overall AVG' 34.5 → 42.1 includes math).
  • Beats data-free baselines on 8B math AVG: 58.2 vs R-Zero 54.7 (+6.4%), Absolute Zero 52.6 (+10.6%), Socratic-Zero 56.1 (+3.7%) — the last despite Socratic-Zero relying on external OpenAI APIs; the base model given the tool zero-shot only reaches 53.2.
  • Qwen3-4B-Base: math AVG 42.6 → 52.5; general Overall AVG 27.1 → 37.6 (SuperGPQA 20.9 → 29.9, MMLU-Pro 37.4 → 55.9, BBEH 7.57 → 12.0).
  • Co-evolution is measurable: the frozen Iter-1 executor's pass rate on curricula from iterations 1/2/3 falls 64.0% → 58.5% → 51.0% while average tool calls rise 1.65 → 2.10 → 2.60; 8B math AVG climbs 55.1 → 56.5 → 58.2 across the three iterations.
  • Ablations (8B math AVG, full Agent0 = 58.2): 46.8 without curriculum-agent training, 48.7 without the tool reward, 47.9 without the repetition penalty, 56.2 with vanilla GRPO instead of ADPO, 55.9 without multi-turn; 4-turn vs 1-turn curriculum generation adds 3.4% overall.

Key advantages

  • Genuinely zero human data: both agents start from the same base model, and tasks, pseudo-labels (executor majority vote), and training rewards (uncertainty, tool use) are all self-generated — no external corpus or annotations enter training.
  • Breaks the self-play capability ceiling the paper identifies in prior work: difficulty targeting (p̂ ≈ 0.5) plus an explicit tool-use reward measurably escalates task complexity iteration over iteration (Table 5) instead of stagnating at the base model's level.
  • ADPO tackles the pseudo-label noise inherent to self-play RL head-on: ambiguity-scaled advantages plus dynamic trust regions beat vanilla GRPO by 2 math points (58.2 vs 56.2).

Limitations

  • Pseudo-labels are majority votes, so label noise on ambiguous tasks is inherent; ADPO only downweights unreliable signals rather than eliminating them (the paper's own motivation for ambiguity-aware scaling).
  • The paper concedes that closed-loop self-evolution without the external tool 'risks mode collapse and curriculum stagnation' because it is bounded by the model's inherent knowledge — the sandboxed code interpreter is load-bearing.
  • The curriculum prompt casts the generator as a competition-math problem setter; coverage beyond math is shown only as transfer to three general benchmarks, on Qwen3-4B/8B-Base alone, and the paper is labeled 'preliminary work'.
  • The pipeline is data-free but not external-model-free: Appendix A uses a GPT-4o answer-checking judge (temperature 0.1); compute demand is heavy (k=10 executor samples per task for both curriculum reward and pseudo-labels, 16 rollout groups, multi-turn sandbox calls), though the paper reports no GPU budget.

Where it fits the RSI arc

The zero-human-data extreme of stage-6 multi-agent self-improvement: a curriculum/executor symbiosis in the Absolute Zero / R-Zero / Socratic-Zero lineage, distinguished by putting tool-integrated reasoning inside the loop so task complexity ratchets past the base model's ceiling instead of stagnating.
