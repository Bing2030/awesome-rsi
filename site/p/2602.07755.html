Learning to Continually Learn via Meta-learning Agentic Memory Designs

Yiming Xiong, Shengran Hu, Jeff Clune

arXiv 2026 · 2026

Local PDFOnlineCode

TL;DR

ALMA meta-learns the memory design itself: a GPT-5 Meta Agent searches memory designs written as executable Python, reflecting on archived designs and their eval logs, and the discovered designs beat Trajectory Retrieval, ReasoningBank, Dynamic Cheatsheet and G-Memory on all four sequential-decision benchmarks.

Abstract

The statelessness of foundation models bottlenecks agentic systems' ability to continually learn, a core capability for long-horizon reasoning and adaptation. To address this limitation, agentic systems commonly incorporate memory modules to retain and reuse past experience, aiming for continual learning during test time. However, most existing memory designs are human-crafted and fixed, which limits their ability to adapt to the diversity and non-stationarity of real-world tasks. In this paper, we introduce ALMA (Automated meta-Learning of Memory designs for Agentic systems), a framework that meta-learns memory designs to replace hand-engineered memory designs, therefore minimizing human effort and enabling agentic systems to be continual learners across diverse domains. Our approach employs a Meta Agent that searches over memory designs expressed as executable code in an open-ended manner, theoretically allowing the discovery of arbitrary memory designs, including database schemas as well as their retrieval and update mechanisms. Extensive experiments across four sequential decision-making domains demonstrate that the learned memory designs enable more effective and efficient learning from experience than state-of-the-art human-crafted memory designs on all benchmarks. When developed and deployed safely, ALMA represents a step toward self-improving AI systems that learn to be adaptive, continual learners.

Method

The Meta Agent (GPT-5) runs open-ended exploration over memory designs expressed as executable Python — code is the search space, so Turing completeness theoretically admits any design. Designs implement two abstract classes: MemoStructure with general_update/general_retrieve orchestrating sub-module layers, and Sub_memo_layer with its own update/retrieve and optional database; layers chain, so one sub-module's output feeds the next. Each step samples up to 5 archived designs without replacement (probability set by success rate and inverse visit count, tau=0.5, alpha=0.5 visit penalty, all probabilities non-zero), reflects on the sampled design's source, success rate and interaction logs to plan, implements a new design in code, trial-runs it (up to 3 debugger reflections on runtime errors), then evaluates and archives it with metrics and logs. 11 steps discover 43 designs. Evaluation is two-phase: memory is collected from memory-free trajectories, then deployment success rate is measured (static mode during learning, dynamic mode for distribution shift).

Key results

  • GPT-5-nano agentic system, four benchmarks: overall success 6.1% (no memory) to 12.3% (+6.2) for the best-learned design, above every human baseline (G-Memory 7.7, Trajectory Retrieval 8.6, ReasoningBank 7.5, Dynamic Cheatsheet 7.2); ALFWorld 2.9% to 12.4% (+9.5), Baba Is AI 9.5% to 19.0% (+9.5).
  • Transferred unchanged to a stronger GPT-5-mini agentic system: overall 41.1% (no memory) to 53.9% (+12.8), again above all human baselines; ALFWorld 67.6% to 87.1% (+19.5). The 12.8 vs 6.2 delta of 6.6% exceeds that of every human-designed memory, i.e. learned designs help stronger models more.
  • Ablation, greedy search on ALFWorld at the same 43-design budget: best-learned 11.9% (GPT-5-nano) and 77.1% (GPT-5-mini) versus 12.4% and 87.1% from open-ended exploration — the archive's stepping-stone sampling is what buys the gain.
  • Task distribution shift (memory collected from 70 valid-seen ALFWorld tasks, deployed in dynamic mode on valid unseen, GPT-5-mini): learned design 84.1%, outperforming all human baselines; Fig. 4 shows it also reaches higher success sooner as collection task count grows (better sample efficiency).
  • Cost (Fig. 6): 53.9% average success at $0.09 end-to-end memory cost, lower than all handcrafted baselines, with 1,319 retrieved tokens per task versus 9,149 (Trajectory Retrieval), 6,095 (G-Memory) and 2,258 (Dynamic Cheatsheet).

Key advantages

  • The searched object is the memory architecture itself — which databases exist (embedding, graph, dictionary), what is stored, how it is retrieved and updated — as one evolvable Python file, so it sits a meta-level above this catalog's fixed memory designs (ACE playbooks, G-Memory, Dynamic Cheatsheet) rather than tuning them.
  • It specializes per domain instead of reusing one recipe: Fig. 3 shows learned ALFWorld/TextWorld designs built on spatial relations, affordance graphs and trajectory schemas, while Baba Is AI and MiniHack designs converge on abstract strategy libraries and plan synthesis.
  • Open-ended archive search is shown to beat greedy selection at equal exploration budget (Appendix C.2, Fig. 14), and the resulting code plus logs are the artifact — the learned design transfers across evaluator FMs without retuning.
  • Efficiency falls out without being optimized for: no cost term in the objective, yet the best-learned design is cheaper per memory than every handcrafted baseline, which the authors read as an argument for adding multi-objective Pareto search as future work.

Limitations

  • Memory designs are learned offline against a fixed learning set; the authors deliberately skip online learning of designs because evaluating each candidate needs many rollouts and would blow the compute budget — an adaptive continual learner should discover designs from dynamic data.
  • Scope is token-level memory only: parametric and latent memory are explicitly out of scope, chosen because explicit token memory evaluates faster without extra model training and is more interpretable and transferable.
  • Model-generated memory code executes inside the agentic loop, so designs are run in isolated sandboxes and human-inspected for harmful behavior such as prompt injection; the paper calls for systematic inspection as the system scales.
  • Evidence is four text-based sequential decision-making benchmarks (ALFWorld, TextWorld, Baba Is AI, MiniHack) with one fixed agentic system per run; each domain needs its own 11-step, 43-design search.
