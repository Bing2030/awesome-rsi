Mathematical Discoveries from Program Search with Large Language Models

Bernardino Romera-Paredes, Mohammadamin Barekatain, Alexander Novikov, et al. (Google DeepMind)

Nature 2024 · 2024

Local PDFOnlineCode

TL;DR

A frozen LLM proposes candidate functions in a problem skeleton; a separate evaluator scores them; the best are fed back as few-shot examples — an evolutionary loop that found new mathematics.

Abstract

Article Mathematical discoveries from program search with large language models https://doi.org/10.1038/s41586-023-06924-6

Method

A frozen (never fine-tuned) LLM proposes candidate functions in a problem skeleton; a separate evaluator scores them; the best are injected back as few-shot examples in the prompt, forming an evolutionary loop. Discovered new cap-set constructions and a better bin-packing heuristic — genuine mathematical novelty.

Key results

  • Discovered new cap-set constructions (size 512 in dimension 8) — the first progress on the problem in years.
  • Also found an improved online bin-packing heuristic.

Limitations

  • Needs a clean, fast evaluator; only works for problems expressible as program search.

Where it fits the RSI arc

The clearest proof that LLM + evaluator + evolution can produce *novel* results humans hadn't found. The model/evaluator split is the key lesson AlphaEvolve scales up.

How to read it

Read the evaluate→select→prompt loop (§2–3) and the cap-set result. The DeepMind blog is a good companion.
