AutoHarness: Improving LLM Agents by Automatically Synthesizing a Code Harness

Xinghua Lou, Miguel Lázaro-Gredilla, Antoine Dedieu, Carter Wendelken, Wolfgang Lehrach, Kevin P. Murphy

arXiv 2026 · 2026

Local PDFOnline

TL;DR

Gemini-2.5-Flash synthesizes its own Python harness by tree-searching code refinements against environment feedback, eliminating all illegal moves across 145 TextArena games and letting the small model beat Gemini-2.5-Pro.

Abstract

Despite significant strides in language models in the last few years, when used as agents, such models often try to perform actions that are not just suboptimal for a given state, but are strictly prohibited by the external environment. For example, in the recent Kaggle GameArena chess competition, 78% of Gemini-2.5-Flash losses were attributed to illegal moves. Often people manually write "harnesses" around LLMs to prevent such failures. In this paper, we demonstrate that Gemini-2.5-Flash can automatically synthesize such a code harness, using a small number of rounds of iterative code refinement given feedback from the (game) environment. The resulting harness prevents all illegal moves in 145 different TextArena games (both 1-player and 2-player), enabling the smaller Gemini-2.5-Flash model to outperform larger models, such as Gemini-2.5-Pro. Pushing our technique to the limit, we can get Gemini-2.5-Flash to generate the entire policy in code, thus eliminating the need to use the LLM at decision making time. The resulting code-policy receives a higher average reward than Gemini-2.5-Pro and GPT-5.2-High on 16 TextArena 1-player games. Our results show that using a smaller model to synthesize a custom code harness (or entire policy) can outperform a much larger model, while also being more cost effective.

Method

Code-as-harness frames the agent as an LLM plus a harness the LLM writes itself. Search keeps a tree of Python code hypotheses; Thompson sampling (weight 1.0) selects which node to refine, scoring nodes by mean legal-action accuracy. A Refiner (Gemini-2.5-Flash, prompted in App. B.2 with the game description, board traces and error feedback) mutates the code, while a Critic consolidates errors from up to 5 failed steps. Rollouts run 10 parallel environments to at most 1000 steps, terminating on an illegal move or code failure. Three templates exist: harness-as-action-filter (propose_action() enumerates moves, the LLM ranks them), harness-as-action-verifier (the LLM proposes, is_legal_action() verifies, and rejection re-prompts with an 'illegal action' warning), and harness-as-policy (pure Python, no LLM at test time). Refinement is asymmetric: when is_legal_action() returns True but the action is illegal both functions are refined; when it returns False only propose_action() is.

Key results

  • Legal-action harness across 145 TextArena games (all 1P/2P games minus 9 free-form-dialog ones, with 'Available Moves' hints stripped from observations): a 1.0 legal-action rate on every game, measured on 1000-step rollouts over 10 seeds each (App. Table 1). Training averaged 14.5 tree-search iterations, with 19/32 eval games finishing under 10.
  • 2P play (16 games, 40 matches each): Gemini-2.5-Flash+Harness wins 9/16 against Gemini-2.5-Pro, a 56.3% win rate to Pro's 38.2%, and 12/16 against vanilla Flash, 64.8%.
  • 1P play (16 games, 20 matches each): 0.745 average reward versus 0.707 for Gemini-2.5-Pro and 0.673 for Gemini-2.5-Flash; higher than Pro in 8/16 games, tied in 5/16.
  • Harness-as-policy (16 1P games): pure-code policies trained with H = 0 if illegal else 0.5 + 0.5r average 0.870 reward, above GPT-5.2-High (0.844), Gemini-2.5-Pro (0.707) and GPT-5.2 (0.635), in 89.4 iterations on average (cap 256, final heuristic 0.939), at near-zero test-time cost against roughly $640 for the GPT-5.2 runs.
  • Motivating failure: in the Kaggle GameArena chess competition, 78% of Gemini-2.5-Flash losses were attributed to illegal moves rather than strategic blunders.

Key advantages

  • Small-model synthesis beats scale: a harness written by Gemini-2.5-Flash lets it outplay Gemini-2.5-Pro on 2P win rate and 1P reward, and the pure-code policy variant beats GPT-5.2-High.
  • The legality checker is learned from board text plus execution feedback with hints removed, so no hand-written per-game validity rule is needed and one loop covers 145 games.
  • Gradient-free and cheap: no fine-tuning, the artifact is searchable source code, and the policy variant removes LLM calls from inference entirely.
  • The search is explicit rather than one-shot: tree search over code hypotheses with Thompson sampling is designed to trade exploration of distinct logic structures against refining a partly working harness.

Limitations

  • One harness per environment: no transfer or reuse across games is demonstrated; distilling harnesses back into the base LLM and building a reusable library are left as future work.
  • Harness-as-policy is only shown on 1P games; the paper states 2P play would need MCTS-like runtime search plus a learned code world model, which it does not attempt.
  • Evaluation is TextArena text games with one model family (Gemini-2.5-Flash), and end-to-end agent results use 16 + 16 games rather than all 145.
  • No ablation isolates the Thompson-sampled tree search from plain iterative refinement, and the policy variant's final heuristic is 0.939 rather than fully legal.
