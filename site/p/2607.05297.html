MetaSkill-Evolve: Recursive Self-Improvement of LLM Agents via Two-Timescale Meta-Skill Evolution

Zefeng Wang, Minxi Yan, Jinhe Bi, Sikuan Yan, Volker Tresp, Yunpu Ma

arXiv 2026 · 2026

Local PDFOnline

TL;DR

MetaSkill-Evolve makes skill self-improvement recursive: every branch carries a task skill plus a meta-skill m=(ψ,σ,α,π,ε) that parameterises the Analyzer/Retriever/Allocator/Proposer/Evolver pipeline, updated on a slower loop by that same pipeline. Frozen Gemma-4 31B gains +23.54/+16.09/+1.92 on OfficeQA/SealQA/ALFWorld.

Abstract

Recent LLM agents tackle increasingly long-horizon, open-ended tasks, and external skills, reusable procedural knowledge supplied to the agent, further extend this capability. However, a fixed, hand-authored skill is rarely optimal, and cannot adapt to the diversity of tasks an agent encounters. Self-improving agents address this by rewriting their own skill files from execution traces, yielding meaningful gains on challenging benchmarks. Yet such self-evolution remains non-recursive: it improves only the task skill (what the agent does) while the improvement procedure (how it improves) is authored once and held fixed. We introduce MetaSkill-Evolve, a two-timescale framework that makes agentic skill improvement recursive: every branch carries both a task skill $s$ and a branch-local meta-skill $m=(ψ,σ,α,π,\varepsilon)$ whose five components parameterise the Analyzer, Retriever, Allocator, Proposer, and Evolver agents of the improvement pipeline. Task skills evolve on a fast loop while the meta-skill evolves on a slower one under the same pipeline applied to itself, with no additional model or objective. With all five pipeline agents sharing a single frozen backbone, MetaSkill-Evolve outperforms no-skill, static-skill, and single-level evolution baselines on three agentic benchmarks (OfficeQA, SealQA, ALFWorld), improving held-out test accuracy over the raw backbone by +23.54, +16.09, and +1.92 points respectively.

Method

Each branch state b=(s,m,h) pairs a Markdown task skill s, a branch-local meta-skill m=(ψ,σ,α,π,ε) — one SKILL.md per pipeline agent (Analyzer, Retriever, Allocator, Proposer, Evolver) — and iteration history. Fast loop: restore the branch snapshot from a SQLite DAG, score s on Dtrain, take the worst example, then Analyzer(ψ) emits a ≤15-word failure tag plus diagnosis, Retriever(σ) pulls same-/cross-branch inspirations by tag match (3× over-fetch, LLM re-rank), Allocator(α) sets child budget K∈[1,3], and K Proposer/Evolver children are written to disk, scored on Dval, and committed to the archive only when ΔU>0. Every H=2 iterations the slow loop folds the window's mean ΔU into a synthetic meta-failure trace and reruns the same five agents over the meta-skill files themselves — all five co-edited per round, Proposer sequential, Evolvers parallel. Parents are chosen by η1U+η2P̂+η3N.

Key results

  • Held-out test accuracy with a single frozen Gemma-4 31B shared by all five pipeline agents: 55.32% OfficeQA, 45.26% SealQA, 94.23% ALFWorld — +23.54 / +16.09 / +1.92 over the No-Skill backbone (31.78 / 29.17 / 92.31).
  • The progression is monotonic on both QA benchmarks: Static skill 36.09 / 29.41 (+4.31 / +0.24 over No-Skill), Single-Level Evolution 48.94 / 37.21 (+12.85 / +7.80 over static), full system 55.32 / 45.26 — so the slow loop alone contributes +6.38 / +8.05 points over the identical fast loop with the meta-skill frozen.
  • ALFWorld is near ceiling (No-Skill 92.31%): the static skill regresses to 90.38, single-level evolution recovers exactly to 92.31, and the whole +1.92 comes from meta-skill updates.
  • Component ablation (§4.3, Table 3): −α (Allocator frozen at K=2) costs 19.7 points on OfficeQA (55.32→35.58) and −π 17.7 (→37.59), but on SealQA the dominant component flips to π (45.26→36.84), and on ALFWorld π again (94.23→86.54) — no single ablation matches the full system.
  • Horizon sweep with three meta-updates held fixed: H=2 beats H=8 everywhere (OfficeQA 48.94→41.35→39.84, SealQA 44.14 / 44.14 / 43.24, ALFWorld 90.38 / 90.38 / 88.46), and removing only cross-branch retrieval returns ALFWorld exactly to the Single-Level 92.31.

Key advantages

  • Names and optimises the quantity fixed-meta evolution ignores: meta-productivity P(m|s) = expected per-child ΔU over K proposals, estimated as the mean ΔU of a node's children, balanced against utility and novelty in the frontier score η1U+η2P̂+η3N with N=1/(1+times_selected). Each η=0 ablation exposes a distinct failure mode (locked high-utility nodes, single-lineage collapse, noisy single-child gains), so frontier selection is the interpretable lever rather than a hidden heuristic.
  • The recursion costs nothing architecturally: every meta-skill component is a Markdown SKILL.md in the same format the pipeline already consumes, so the identical five agents improve m with no extra model, no fine-tuning and no new objective — a bounded, one-level reflexive application of the improvement operator to itself.
  • Two typed stages beyond the standard analyze→propose→evolve loop: a Retriever for cross-branch sharing (p_cross=0.2, L_same=3, L_cross=2, plus inspiration edges in the graph) and an Allocator whose adaptive child budget widens after stagnation — the OfficeQA result says the widening is what produces a successful child at all.
  • Full provenance in a persistent SQLite DAG: lineage and inspiration edges, failed children (ΔU≤0) retained as inspiration even though ineligible as parents, and branch state restored from the node record before each iteration so lineages cannot leak into each other and previously deprioritised branches can be revisited.

Limitations

  • The recursion is bounded and one-level: the five-agent pipeline's roles and wiring are themselves fixed — only the meta-skill files evolve, a limitation the paper states explicitly.
  • Evidence covers three curated benchmarks with verifiable rewards; transfer to open-ended, long-horizon real-world tasks with noisier feedback is untested (paper's own limitation).
  • The meta-update horizon H is a fixed hyperparameter, not adaptively scheduled: defaulting to H=2 and sweeping to H=8 costs 9.1 points on OfficeQA, so results are coupled to a hand-tuned stability/reactivity trade-off.
  • The budget is small and the splits are thin — the default run is 5 fast iterations with two meta-updates scored on roughly 87–107 test items — and on saturated ALFWorld a small validation split starves the loop of failures (enlarging val 0.10→0.25 at tr=0.15 lifts 90.57→93.02).
