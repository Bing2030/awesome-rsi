Gödel Agent: A Self-Referential Agent Framework for Recursive Self-Improvement

Xunjian Yin, Xinyi Wang, Liangming Pan, Li Lin, Xiaojun Wan, William Yang Wang

ACL 2025 · 2025

Local PDFOnlineCode

TL;DR

An LLM agent that reads and rewrites its own Python source in runtime memory — monkey patching, not a fixed optimizer — lifting MGSM accuracy to 64.2% (Meta Agent Search 53.4%) and DROP F1 to 80.9 under GPT-3.5.

Abstract

The rapid advancement of large language models (LLMs) has significantly enhanced the capabilities of AI-driven agents across various tasks. However, existing agentic systems, whether based on fixed pipeline algorithms or pre-defined meta-learning frameworks, cannot search the whole agent design space due to the restriction of human-designed components, and thus might miss the globally optimal agent design. In this paper, we introduce Gödel Agent, a self-evolving framework inspired by the Gödel machine, enabling agents to recursively improve themselves without relying on predefined routines or fixed optimization algorithms. Gödel Agent leverages LLMs to dynamically modify its own logic and behavior, guided solely by high-level objectives through prompting. Experimental results on mathematical reasoning and complex agent tasks demonstrate that implementation of Gödel Agent can achieve continuous self-improvement, surpassing manually crafted agents in performance, efficiency, and generalizability.

Method

Gödel Agent is a single Python agent whose main function is recursive rather than a fixed loop, so its own code stays rewritable mid-run. Self-awareness comes from runtime memory inspection: it introspects the local and global variables holding its functions and classes. Self-modification comes from monkey patching — new code is written into runtime memory to add, replace or remove logic. Its action set is self_inspect, interact, self_update and continue_improve: an LLM decision function f0 emits an action sequence from the goal prompt g and environment feedback r=U(E,pi), the action function executes it, and continue_improve recurses one level deeper. Formally pi_t+1, I_t+1 = I_t(pi_t, I_t, r_t, g) — the optimizer updates itself, not just the policy, and the whole code base is rewritten after each execution. Auxiliary tools (think-before-acting, error handling, Python/Bash execution, LLM calls) only accelerate convergence.

Key results

  • Table 1, GPT-3.5 for all tests: Gödel-base beats Meta Agent Search on all four benchmarks — DROP F1 80.9±0.8 vs 79.4±0.8, MGSM 64.2±3.4 vs 53.4±3.5 (10.8 points, the paper's '11%'), MMLU 70.9±3.1 vs 69.6±3.2, GPQA 34.9±3.3 vs 34.6±3.2. Hand-designed baselines sit far below (CoT: 64.2/28.0/65.4/29.2).
  • Unconstrained Gödel-free scores 90.5 / 90.6 / 87.9 / 55.7 (DROP / MGSM / MMLU / GPQA), which the authors attribute to the agent spontaneously requesting help from GPT-4o.
  • Cost: one complete run — 30 recursive self-improvements across all four datasets — costs about $15 versus $300 for Meta Agent Search, because continuous self-optimization converges faster; the main cost driver is the agent's growing historical memory.
  • Game of 24 case study: after six failed optimization attempts the agent discards its LLM prompting strategy and rewrites itself to use a search algorithm, reaching 100% accuracy; adding code-assisted verification raises performance by over 10% and reattempting with additional data by more than 15%.
  • Robustness over 100 MGSM trials: 92% show temporary performance drops and 4% terminate unexpectedly (usually after it edits its own recursive-improvement module), but only 14% end worse than the initial policy. Ablating 'thinking' costs 13.4 points and error handling 14.8 (50.8 and 49.4 vs 64.2); code running (-7.1) and LLM calling (-3.8) matter little.

Key advantages

  • Removes the hand-designed meta-level that bounds ADAS / Meta Agent Search: because both the policy and the learning algorithm I are updated, the search space includes the optimizer itself, so the agent can replace its reasoning strategy outright — the Game of 24 switch from prompting to search is the concrete evidence.
  • One implementation transfers across reading comprehension, multilingual math, MMLU and GPQA with only a task-specific environment description and utility function, versus Meta Agent Search's per-task module design.
  • Cheap and empirically robust: roughly $15 per full evolution against $300 for Meta Agent Search, and in 86% of 100 trials it recovers from its own bad edits, often by reverting to a previously better algorithm.
  • Makes the Gödel machine measurable at LLM scale: an explicit recursion between policy and self-referential learning algorithm, a runnable Algorithm 1, and what the authors present as the first fully self-referential LLM agent framework, implemented with monkey patching.

Limitations

  • No direct comparison with the most heavily engineered agent systems such as OpenDevin: the agent must construct all task code autonomously, and the authors say it is unrealistic to expect it to beat systems built over months or years — the experiments demonstrate feasibility of recursive self-improvement, not state of the art.
  • Gains are bounded by the base LLM: on Game of 24 no initial-policy variant let the agent outperform a hand-written Tree of Thought, and the authors doubt it can innovate beyond state-of-the-art algorithms until LLM capability improves.
  • Not goal-preserving by construction: self-modification caused 4% of trials to terminate irrecoverably by breaking the recursive-improvement module, and the unconstrained runs' large gains came partly from calling stronger models (GPT-4o), i.e. from leaving the intended setup.
  • The authors flag an unexplored ceiling — as the system grows more complex through self-optimization it may need exponentially more intelligence to understand itself, so a fully self-referential agent may lose that property as it evolves.
