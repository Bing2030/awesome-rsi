Chain-of-Verification Reduces Hallucination in Large Language Models

Shehzaad Dhuliawala, Mojtaba Komeili, Jing Xu, Roberta Raileanu, Xian Li, Asli Celikyilmaz, Jason Weston

Findings of ACL 2024 · 2024

Local PDFOnline

TL;DR

Chain-of-Verification (CoVe): draft an answer, plan verification questions about its factual claims, answer those questions without the draft in context, then regenerate. Wikidata list precision 0.17 -> 0.36 and biography FactScore 55.9 -> 71.4, with no tools or retraining.

Abstract

Generation of plausible yet incorrect factual information, termed hallucination, is an unsolved issue in large language models. We study the ability of language models to deliberate on the responses they give in order to correct their mistakes. We develop the Chain-of-Verification (CoVe) method whereby the model first (i) drafts an initial response; then (ii) plans verification questions to fact-check its draft; (iii) answers those questions independently so the answers are not biased by other responses; and (iv) generates its final verified response. In experiments, we show CoVe decreases hallucinations across a variety of tasks, from list-based questions from Wikidata, closed book MultiSpanQA and longform text generation.

Method

Four prompted steps on one frozen base LLM (Llama 65B, 3 few-shot examples, greedy decoding): (1) generate a baseline response; (2) plan verification questions covering the draft's factual claims, freely phrased by the model rather than templated; (3) execute those verifications; (4) generate the final verified response conditioned on the question-answer pairs. Step 3 has four variants differing in what may attend to what: joint (plan and answer in one prompt, so answers still see the draft), 2-step (questions answered with the draft removed from context), factored (each question answered in its own prompt, so no draft and no cross-question interference, and prompts batch in parallel), and factor+revise (adds one cross-check prompt per question emitting CONSISTENT / INCONSISTENT / PARTIALLY CONSISTENT). The final prompt presents the verification answers as coming from "another source".

Key results

  • Wikidata list questions (micro precision, Llama 65B few-shot): 0.17 -> 0.36 with 2-step CoVe, driven by hallucinations collapsing (negatives 2.95 -> 0.68) while correct entities dip only slightly (0.59 -> 0.38).
  • Harder Wiki-Category list task: precision 0.12 -> 0.22 with factored CoVe (negatives 4.05 -> 1.52); factored beats joint on every task.
  • Closed-book MultiSpanQA: F1 0.39 -> 0.48 (factored), a 23% gain from both precision (0.40 -> 0.50) and recall (0.38 -> 0.46).
  • Biography generation (FactScore, Min et al. metric): 55.9 -> 71.4 with factor+revise, +28%, at 16.6 -> 12.3 average facts; this beats ChatGPT 58.7 and retrieval-augmented PerplexityAI 61.6 using only the base model (joint 60.8, factored 63.7).
  • Diagnostics: only ~17% of the few-shot baseline's list entities are correct, yet ~70% of those same facts are answered correctly when queried individually; question form matters (Table 4, Wiki-Category) - LLM-written open questions (factored 0.22) beat yes/no (0.19) and templated rule-based (0.16); and neither instruction tuning nor CoT helps (Llama 2 70B Chat zero-shot F1 0.20 vs few-shot Llama 65B 0.39).

Key advantages

  • Reduces hallucination with no retrieval, no tools and no weight updates - purely inference-time deliberation on a frozen model - yet still out-fact-scores ChatGPT and a retrieval-augmented system on biographies.
  • Isolates attention control as the causal mechanism rather than crediting 'more compute': joint < 2-step < factored across tasks shows the gain comes from stopping verification from attending to the hallucinated draft, and Table 4 shows generated questions beat templated heuristics.
  • Is not precision bought with recall: hallucinated entities fall 2.95 -> 0.68 while correct ones only dip 0.59 -> 0.38, and since FactScore is normalized, producing fewer facts is not the explanation (clipping Llama 2 to 10 sentences only moved 41.3 -> 42.7).
  • Supplies the reusable design pattern for self-checking - decompose the check into short, independently answerable questions and keep each one blind to the text being checked - which later verification and memory-evolution loops inherit.

Limitations

  • CoVe does not remove hallucinations, only reduces them; the paper's own Section 6 concedes it can still produce incorrect or misleading output.
  • Scope is directly stated factual inaccuracies (and, on Wikidata/Wiki-Category, listed entities) - not errors inside reasoning steps and not opinions.
  • The ceiling is the base model's own knowledge, since verification is performed by the same weights: Figure 2 shows retrieval-augmented PerplexityAI still wins on very rare facts, and the paper names tool use as the obvious extension.
  • Extra cost: more generated tokens, like chain-of-thought, and factored CoVe runs many more prompts (batchable, but no cost analysis or variance/error bars are reported across the four tasks).

Where it fits the RSI arc

Stage 3, self-verification - the positive counterpart to the stage's negative result. CoVe works where intrinsic self-correction fails because verification is decomposed into short, independent, more-answerable questions instead of asking the model to judge its own reasoning. Pairs with Self-Refine (the loop it disagrees with), CRITIC (the tool-grounded version of step 3) and Self-Consistency.
