Harness-Zero: Harness Distillation via Agent-as-Harness

Haoran Ye, Yuxing Lu, Haonan Dong, Zhaochen Su, Guojie Song

arXiv 2026 · 2026

Local PDFOnlineCode

TL;DR

Distills an optimized agent harness into model weights: a harnessing agent reviews and rewrites the student's responses at training time, and SFT on those trajectories moves the behavior into the model — so the specialized harness can be removed at deployment and the gains remain (23.3% → 44.3% macro-average, beating the 41.7% the base model gets with the optimized harness still attached).

Abstract

Agent harnesses, the external systems that mediate model-environment interaction, can substantially improve agent performance, but their gains remain tied to the harness at deployment. Because the best harness varies across domains, instances, and models, a general-purpose agent must either settle for a suboptimal shared harness or route among an ever-growing set of specialized ones. We therefore study agent harness distillation: using a domain- or instance-optimized harness as training-time guidance and transferring the behaviors it induces into model weights, so that its gains survive under a single fixed target harness. The challenge is that the two harnesses differ in action space and available information, so guidance from the optimized harness cannot serve directly as supervision for the target one. We introduce Harness-Zero, which enables harness distillation through agent-as-harness. Guided by the optimized harness, a harnessing agent corrects student responses before execution in the target harness's action space, turning harness guidance into training demonstrations. Fine-tuning on the resulting trajectories internalizes harness-induced behavior into the model, so the specialized harness can be removed at deployment. Our experiments spanning knowledge work, tool use, and science domains show that: (1) For frontier LLMs using the same evolved harness, agent-as-harness outperforms code-as-harness. (2) With the specialized harness removed at deployment, Harness-Zero improves the base model's macro-average task success from 23.3% to 44.3%, even exceeding the 41.7% it reaches with that harness still attached. (3) Harness-Zero recovers harness-induced behaviors absent from the base model, with 82.3% average recovery across 28 patterns in the three domains.

Method

Three stages. (1) Evolve a student-side harness h* on training tasks, then Adapt it into a private reference harness K for a separate harnessing agent — e.g. a middleware rule that blocks risky actions becomes a review-time warning. (2) Agent-as-harness trajectory collection: the student runs under a fixed minimal target harness h (one bash tool, fixed system prompt); before any response is executed, the harnessing agent reviews it against K and either PASSes it unchanged or REPLACEs it with a complete response valid in h's action space; only the accepted response enters the student-visible trajectory and the review stays private. (3) SFT on the reviewed rollouts (masking reviewer-perspective reasoning), then deploy under h alone.

Key results

  • Agent-as-harness beats code-as-harness on frontier models: 81.1% vs 78.1% averaged across six benchmark–model settings.
  • Harness distillation into Qwen3.5-9B lifts macro-average task success from 23.3% to 44.3% across SpreadsheetBench / AppWorld / USPTO — above the 41.7% the base model reaches with the evolved harness h* still attached (a 90.1% relative improvement).
  • 82.3% average recovery of 28 harness-induced behavior patterns (memory, skill, tool, middleware) absent from the base model — direct evidence the behavior moved into the weights.
  • Supervision-source ablation: harness-guided review (30%) far exceeds direct trajectories from a stronger model, trajectories under h*, review without K, or review given only the task answer (3–15%).

Key advantages

  • Distillation across incompatible action spaces, which is what makes the rest work: trajectories collected under h* are unusable for imitation under h — SFT on them drops the student from 12% to 3% because the model emits harness-tool calls that h does not provide. Agent-as-harness sidesteps the mismatch by expressing every correction as a complete response valid in h, and reaches 30% from the same base.
  • Removes the harness entirely rather than routing around it: the deployed system is (π_θ̂, h) with no h*, K, or harnessing agent, and the distilled 9B still beats the base model with h* mounted (44.3% vs 41.7%). Neither general-purpose harness helps that base model at all (DeepAgents 20.5% and Claude Code 15.9% vs 23.3% under minimal h), so the gain is specific to the evolved harness's behavior, now in the weights.
  • Shows collection success does not predict distillation value: review with oracle answers scores 98.6% collection success but yields a 15% student, while K — which contains no task answers and reaches only 59.4% collection success — yields 30%. The signal is procedural guidance the student can execute independently, not correct answers.
  • The 81.1% vs 78.1% margin cannot be credited to a stronger supervisor: in §4.2 the same model plays both student and harnessing agent, and with an empty K the same wrapper averages only 69.2%, so the gain comes from the adapted reference harness rather than from review per se.

Limitations

  • Depends on a capable harnessing model; with weaker models review can become harmful and agent-as-harness loses its edge over code-as-harness.
  • Reviewing every proposal multiplies collection cost (an extra model call per step; ~2.4× USPTO latency) — though the overhead is absent after distillation.
  • Some harness mechanisms (notably context management) are not fully expressible as student responses, and SFT may not fully internalize deep domain knowledge — so it narrows rather than removes the need for a harness.

Where it fits the RSI arc

The clearest demonstration yet of the harness→weight transfer rsif's policy surface points at: an optimized harness's induced behaviors are distilled into model parameters via a temporary reviewing agent, then the harness is removed. rsif evolves its artifacts directly under programmatic gates; Harness-Zero shows the complementary move — that harness gains can be converted into training signal and folded back into weights, collapsing a harness collection into one minimal harness. Its agent-as-harness-beats-code-as-harness result is the key empirical claim to weigh against rsif's code-as-substrate stance.

How to read it

Read §3 for the evolve→adapt→review→SFT pipeline (the PASS/REPLACE review boundary and why the review stays private), then §4.2's agent-as-harness vs code-as-harness comparison and §4.4's supervision-source ablation (30% vs 3–15%) as the tightest evidence for review quality.
