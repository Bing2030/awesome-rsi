DeepSeek Harness

repo · substrate

GitHub

What it does

DeepSeek's open-source agent harness (`dsh`): a TypeScript monorepo where every component — model adapters, tool registry, session log, the agent loop itself — is a Cordis plugin, composed at boot into replaceable profiles (web, headless, sdk, sdk-minimal, acp). MIT, developer preview.

How it works

  • Everything-is-a-plugin via Cordis (its design is formalized in arXiv 2608.25512, 'A Programming Paradigm for Spatiotemporal Composability'): plugins contribute services, typed events, and reversible effects to one shared context; there is no privileged core — the model adapter, tool registry, session log, and agent loop (`ctx.agentLoop`) are all rows replaceable from config, and registrations unwind when their plugin unloads.
  • Boot composition is ordered layers: each profile stacks bundles, then the profile's `cordis.patch.yml`, then the home-level one, then `--patch` overlays; a patch targets a config row by id and replaces its whole config, and `dsh --profile web --dump-config` prints the exact tree your machine boots.
  • The session log is the source of truth: an append-only `SessionEvent` log under a runtime invariant that anything reaching a model request must be reconstructable from it ('model-visible means logged'); `deriveMessages()` projects model history, and storage is versioned `session.vN.jsonl[.zstd]` generations with one-step migration chains — fork, resume, transcripts, and telemetry all derive from it.
  • Tools register with `defineTool` (typed params, validated calls, allow/deny/ask policy) and their schemas join prompt assembly automatically; native function-calling or PTC mode, where a `run_code` program calls registry tools through nested sub-dispatches — each logged for reconstruction, only the outer curated result entering model history; `maxParallelToolCalls` defaults to 10. Capability seams (Service Definition + Provider + Consumer) swap fs and subprocess together, so one provider change moves Bash, PTY, and LSP to a remote sandbox with no forks.

Key advantages

  • The interception surface a self-modification experiment needs is first-class, not monkey-patched: `agent/pre-step` rewrites or rejects claimed input, `agent/request` reroutes model calls, `tools/pre-execute|execute|post-execute` guard tool runs, and `agent/turn-stopping` stops a turn — every extension point is a typed event with a documented producer/consumer map.
  • Harness-as-data: because the running agent is a patchable config tree with YAML-driven HMR, you can inspect, re-compose, or shrink the harness itself (`sdk-minimal` is a complete explicit SDK tree that omits `dsh-base`) through the same mechanism plugins use to extend it.
  • A coordination substrate for multi-agent RSI: experimental Agent Teams on `ctx.agentTeams` (durable roster, task board, mailbox over continuable subagents), forkable sessions at turn boundaries, and swappable subagent providers — including a one-shot provider that delegates a task to a fresh, unattended Claude Code session in the parent workspace.

Install & run

`npx @deepseek-ai/dsh web` — Web UI at http://127.0.0.1:3080 (needs Node.js; `--no-open` skips the browser). From source: `git clone https://github.com/deepseek-ai/deepseek-harness && cd deepseek-harness && pnpm install && pnpm run build && pnpm dsh web`. Other profiles: `dsh --profile headless|sdk|sdk-minimal|acp`.

Learning note

Read docs/architecture.md first — its turn-flow event map and 'where new behavior goes' table are the real spec. Then trace one turn's events end-to-end and study the patch mechanism as the harness self-modification seam. Mind SAFETY.md: unaudited preview that executes model-generated code and third-party plugins.

Repo README

DeepSeek Harness

English | 中文

DeepSeek Harness (dsh) is an open-source agent harness developed by DeepSeek AI.

It is built on an everything-is-a-plugin architecture and powered by Cordis, whose design is described in A Programming Paradigm for Spatiotemporal Composability.

Documentation: https://deepseek-harness.github.io/deepseek-harness/

Developer preview

DeepSeek Harness is in developer preview and iterating rapidly. THERE WILL BE COMPATIBILITY-BREAKING CHANGES.

Review the safety notice before running the project.

Run

Run from npm

Install Node.js, then run:

npx @deepseek-ai/dsh web

The command starts the Web UI at http://127.0.0.1:3080 by default and opens it in the default browser for a local launch. An SSH launch only prints the host URL because the SSH client or editor owns the local forwarded address. Pass --no-open to run the server without opening a browser. See Web UI guide.

Run from source

To run from a repository checkout:

git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web

pnpm run build prepares the repository artifacts. pnpm dsh web uses those built artifacts without rebuilding.
